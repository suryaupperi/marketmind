# marketmind
Developed a Python-based quantitative trading research platform that leverages technical indicators, algorithmic strategy development, and data-driven performance analytics to evaluate swing-trading strategies. Implemented RSI and Bollinger Bands signal generation, realistic trade execution modeling, transaction-cost adjustments, and out-of-sample backtesting to assess strategy performance against buy-and-hold benchmarks. Built an interactive Streamlit dashboard for market data visualization, customizable ticker analysis, and comparative risk-return evaluation.

Technologies: Python, Pandas, NumPy, Streamlit, Quantitative Finance, Algorithmic Trading, Time-Series Analysis, Statistical Performance Evaluation, Backtesting, Data Visualization.
