# marketmind
Developed a Python-based quantitative trading research platform that leverages technical indicators, algorithmic strategy development, and data-driven performance analytics to evaluate swing-trading strategies. Implemented RSI and Bollinger Bands signal generation, realistic trade execution modeling, transaction-cost adjustments, and out-of-sample backtesting to assess strategy performance against buy-and-hold benchmarks. Built an interactive Streamlit dashboard for market data visualization, customizable ticker analysis, and comparative risk-return evaluation.

Skills: Python, Pandas, NumPy, Streamlit, Quantitative Finance, Algorithmic Trading, Time-Series Analysis, Statistical Performance Evaluation, Backtesting, Data Visualization.

To run MarketMind, install Python 3.11 or newer and Git, then clone the repository using `git clone https://github.com/YOUR_USERNAME/MarketMind.git` and navigate into the project folder with `cd MarketMind`. Create and activate a virtual environment using `python3 -m venv .venv` and `source .venv/bin/activate` on Mac/Linux, or `py -m venv .venv` and `.venv\Scripts\Activate.ps1` on Windows PowerShell. Install the required dependencies by running `pip install -r requirements.txt`, then launch the interactive dashboard with `streamlit run dashboard.py`. Open the local URL displayed in the terminal, usually `http://localhost:8501`, to explore stock tickers, configure historical date ranges, test RSI and Bollinger Bands trading strategies, visualize performance, and compare results against a buy-and-hold benchmark.
